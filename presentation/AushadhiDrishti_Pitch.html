Why Gemma 4 is the right tool

  • Vision-native: submits the raw JPEG directly — no OCR pre-pass, no segmentation, no template
  • Reads clinical shorthand: "1-0-1 BD", "OD", "TDS", "SOS", "ac/pc" decoded to structured schedule automatically
  • Zero-shot generalisation across handwriting styles — no labelled prescription dataset required
  • Returns validated JSON with every field separately: name, strength, dose, frequency, timing, duration, uncertainty
  • Replaces an entire OCR + NLP + NER pipeline with a single, auditable API call
  • Edge-capable variants (E2B/E4B) make on-device deployment feasible for rural clinics without cloud dependency

Technical depth

Purpose-built clinical tool, not a chatbot wrapper

Non-obvious engineering decisions

  • Streaming NDJSON telemetry — each pipeline stage reports live with elapsed time; pharmacist sees exactly what is happening, building clinical trust
  • Offline fallback engine — clinical fixtures run without any API key; demonstrable in rural clinics with no internet
  • Brand-to-generic resolver — 200+ Indian brand names (Augmentin, Dolo, Brufen) mapped before interaction matching; most tools skip this step entirely
  • Field-level JSON extraction — strength, dose, units, frequency, timing, duration each returned separately; a wrong unit or frequency is as dangerous as a wrong drug name
  • Scan history with localStorage — every past review is auditable; re-open without re-uploading; individual delete
  • Zero framework dependency — Vanilla JS, CSS design tokens, dark/light mode; no build step, runs on any server
